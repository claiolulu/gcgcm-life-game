# 人生护照项目上下文与进度同步

共享记忆是仓库根目录的 [PROJECT_MEMORY.md](../../../PROJECT_MEMORY.md)。Claude Code 和其他助手都维护这一份，不另建相互冲突的进度副本。

## 开始工作

1. 读取根目录 `CLAUDE.md` 和完整 `PROJECT_MEMORY.md`。
2. 检查当前分支、最新提交与工作区变化；这些可能已被另一位助手更新，记忆中的基线不是永久固定值。
3. 按记忆中的代码地图定位实现，并阅读本次相关代码。发现说明过时，记录差异，不恢复旧功能。

## 开发与验证

- 活动画布与最终护照共用渲染组件、单位及固定模板，不能另写一套近似预览。
- 中文输入、双指缩放、横竖屏、全屏样式面板属于高频回归点；涉及它们时按记忆中的检查清单验证，并如实记录未做的真机检查。
- 数据与离线幂等规则见共享记忆。测试使用隔离数据库，不向真实服务调用重置或演示种子脚本。
- “更新记忆”不授予部署、删除数据或修改另一个项目的权限。

## 结束或交接

更新共享记忆的日期、当前实现、验证/部署状态、未完成项，以及一条简短开发记录。用实际执行结果写状态，不能把构建成功当作部署成功，也不能把后端测试当作手机视觉检查。

开发记录包含：日期与目标、变化及主要文件、验证结果、部署状态、下一步。涉及数据库字段/API/运行命令/产品决定时，同时修改对应现状章节，避免只追加日志而不更新正文。

检查文档链接与差异格式；最终回复简述完成情况和仍需确认的事项。
